## Жёсткие правила (из брифа, раздел 6)
1. Никакой автоотправки: ни сообщений, ни инвайтов, ни комментариев, ни вступлений в чаты от рабочего аккаунта. Сервис готовит текст и открывает чат, отправляет человек.
2. Только открытые каналы и чаты, читаем без вступления. Никаких личных диалогов аккаунта (`/dialogs`, `/messages` личных чатов) — не читать и не хранить.
3. Секреты только в env / зашифрованной интеграции. Ни одного секрета в коде, логах, коммитах.
4. Не ломать текущие данные и логику. Миграции — только добавление (новые таблицы, nullable-поля). Своя миграция со своим префиксом времени (см. ниже).
5. Не выдумывать факты и кейсы. Нет факта — `NOT_FOUND`. Реальные кейсы студии: Свой Хлеб, Fittera, Метод Малова, AZOT (В-сегмент); фонд, музейный проект, телеканал (А/Б — без названий клиентов в тексте, если Никита не разрешил). Цены и сроки в подсказках не писать.

### Контракты между сессиями
- S2 создаёт `Organization` с `source = "telegram"`, контактом `OrganizationContact{type:"telegram", value:"@username"}` и последними постами в `Organization.raw.telegram = { username, title, members, posts: [{id, date, text, link}] }`. После сохранения вызывает существующий `autoQualifyNew(tenantId, ids, { explicit: true })`.
- S1 в квалификации берёт посты из `raw.telegram.posts` как факты для зацепки (как сейчас берёт скан сайта) — через функцию `telegramFacts(org)` из `src/lib/domain/telegram-facts.ts` (её пишет S2; если её ещё нет — S1 пишет минимальную версию с этой сигнатурой: `telegramFacts(raw: unknown): { text: string; link: string | null; date: string }[]`).
- S4 вызывает поиск Telegram через `POST /api/hunt/telegram/searches {niche, city?, limit}` → `{ id }` и показывает его в общей очереди; статус — `GET /api/hunt/telegram/searches/:id` → `{ status: queued|running|completed|failed, found, error }`.
- Сегменты А/Б/В/Г (бриф, раздел 4) — пресеты в `segments.ts` (S1). S4 берёт список ниш для выбора из экспортируемой функции `nichePresets()` в `src/lib/domain/niche-presets.ts` (пишет S4 по брифу, S1 может дополнять).
